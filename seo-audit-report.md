## Технические улучшения производительности — ИСПРАВЛЕНО ✅

### ❌→✅ Два отдельных запроса к Google Fonts (на каждой странице)
Каждая страница загружала шрифты двумя отдельными HTTP-запросами. Объединено в один URL:

```
Было:
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:...">
<link href="https://fonts.googleapis.com/css2?family=Manrope:...">

Стало:
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:...&family=Manrope:...&display=swap">
```

**Экономия:** 1 HTTP-запрос на каждой странице, что уменьшает время до первого байта (TTFB).

### ❌→✅ Отсутствовали preconnect хинты
Добавлены на всех страницах:
```html
<link rel="preconnect" href="https://fonts.googleapis.com"/>
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin/>
<link rel="dns-prefetch" href="https://cdn.tailwindcss.com"/>
```
Это позволяет браузеру заранее установить соединение с серверами шрифтов, сокращая задержку.

### ❌→✅ Отсутствовали lazy loading атрибуты на изображениях
Добавлен `loading="lazy"` на изображения ниже первого экрана, `fetchpriority="high"` — на главный логотип на hero-секции index.html.

## Предупреждения — требуют вашего внимания

### ⚠️ Необходимо заменить домен-заглушку `sharifa.school`
Во всех добавленных тегах используется домен `https://sharifa.ru` — это заглушка. Вам нужно заменить его на ваш реальный домен везде, где он встречается (в canonical, og:url, sitemap.xml, robots.txt, JSON-LD).

Для быстрой замены можно открыть каждый файл и заменить `https://sharifa.ru` на ваш реальный URL.

### ⚠️ Tailwind CSS подключается через CDN (режим разработки)
Файл `https://cdn.tailwindcss.com` — это версия для разработки весом около 3 МБ. В продакшене нужно использовать CLI Tailwind для генерации только используемых классов (~10-30 КБ). Это самое значимое улучшение скорости, которое можно сделать.

**Как исправить:** Установите Tailwind CLI и запустите сборку:
```bash
npm install -D tailwindcss
npx tailwindcss -i ./input.css -o ./output.css --minify
```
Затем подключите `output.css` вместо CDN-скрипта.

### ⚠️ Изображения в hero-секции загружаются через CSS background-image
Фоновые изображения в `<div style="background-image:...">` не могут иметь атрибут `alt` и не индексируются как контент-изображения. Для SEO лучше использовать `<img>` с атрибутом `alt`. Однако это требует более серьёзного рефакторинга HTML.

### ⚠️ Внешние изображения с lh3.googleusercontent.com
Несколько изображений загружаются с CDN Google (lh3.googleusercontent.com). Это снижает контроль над кешированием и производительностью. Рекомендуется загрузить эти изображения локально.

### ⚠️ Отсутствует og:image на всех страницах
Open Graph теги добавлены, но без `og:image`, так как неизвестен финальный URL изображений. Добавьте изображение размером 1200×630 пикселей:
```html
<meta property="og:image" content="https://ВАШ-ДОМЕН/og-image.jpg"/>
<meta property="og:image:width" content="1200"/>
<meta property="og:image:height" content="630"/>
<meta property="og:image:alt" content="Школа Корана SHARIFA"/>
```

## Приоритетный список следующих шагов

1. **Замените домен-заглушку** `sharifa.school` на ваш реальный домен во всех файлах
2. **Добавьте og:image** — создайте красивую обложку 1200×630px и добавьте в Open Graph
3. **Переведите Tailwind на production build** — самое большое улучшение скорости (-3 МБ)
4. **Добавьте H1 на главную страницу** — либо видимый текст вместо/рядом с логотипом, либо `<h1 class="sr-only">Школа Корана SHARIFA — Махачкала</h1>` (скрытый для скринридеров и поисковиков)
5. **Создайте отдельные страницы для каждого филиала** вместо одной динамической branch.html с параметрами
6. **Оптимизируйте локальные фотографии** в папке `photos/` — добавьте сжатие и конвертацию в WebP
7. **Зарегистрируйте сайт** в Яндекс.Вебмастер и Google Search Console, добавьте sitemap.xml
